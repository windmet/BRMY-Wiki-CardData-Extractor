## 5. 工具箱 exe 易用性改造

目标：组员拿到 exe 后只需要"联网更新 → 勾任务 → 打开结果"三步。

建议的实施顺序：

1. **表格面向人**（收益最大、风险最小）
   - 表头去掉"原值"、`Cue`、`KeyTargetValue`、`resolved` 这类开发用语。
   - `Sheet1`、`cards_data` 改成中文表名。
   - 状态统一为"正常 / 待核对 / 缺失"三档。
   - 内部字段和防御性的列挪到 `audit_output` 的 JSON 里。
   - 每次运行额外生成一张"待核对汇总"表，每条注明对应的表和行。
2. **GUI 按任务组织**
   - 首页按用途分组勾选：卡牌 / 语音 / 活动与剧情 / 音乐 / 网站数据，每项一句话说明产出。
   - 模式只留"联网更新（默认）"和"用本地缓存"。
   - 缓存路径、`resource_keys` 等收进"高级"折叠区。
   - 周期、年份、主题改成从 masterdata 读出的下拉框。
   - 加几个预设：版本更新全套 / 只更新语音 / 只出活动表。
   - 运行详情页只在出错时自动展开。
3. **入口和代码清理**
   - 只保留 GUI 一个入口，`sync`/`generate` 留给维护者和 CI。
   - `generate.py`、`gui.py`、`resolve.py` 里重复的任务集合（`MASTERDATA | {...}`）合并成一处。
   - 代码里"原值"出现 22 处、"unresolved"出现 48 处、警告和报错调用 53 处，收敛成统一的待核对机制。
4. **文档**：现在 `docs/` 有 50 份、约 3600 行。压成"组员使用指南"（一页，带截图）和"维护者手册"，历史收尾记录移到 `docs/archive/`。
5. **发布**：PyInstaller 打包，附上组员指南，在 GitHub Release 发布。

## 6. 2.1.0 客户端里可继续利用的东西

- `dump.cs`：完整类表，可替换旧 dump。
  - 剧情播放相关：`story.ChatCommandPlayer`、`StoryController`。
  - 首页语音相关：`HomeVoiceUtil`、`HomeVoiceUtil.PlayedDuoVoiceLog`。可以从这里查双人语音的触发规则，弄清 `KeyTargetValue` 的含义。
- 反汇编方法：
  1. 用 dump.cs 里的 RVA 找到方法；代码段的文件偏移 = RVA − 0x4000。
  2. 用 capstone（arm64）读反汇编。
  3. 被调用函数的名字在 `script.json` 里按地址查。
  4. 浮点常量所在的段要先查 ELF 程序头换算偏移，不能直接用 RVA。
- 解包得到的文件属于外部数据：放在单独目录里，Python 用 `-I`（或 `-P -E`）运行，把路径作为参数传入。

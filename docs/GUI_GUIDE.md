# Wiki GUI 使用说明

当前 GUI 已通过正式源五项任务、离线恢复、取消重试及主要可见布局验收；本地文件选择由用户协助完成，后续本地生成、打开结果和实际 Excel 占用也已验收。当前为本地验收候选，不代表已正式发布。

源码安装后运行 `python -m toolkit gui`；新构建的 `bmc_toolkit.exe` 双击默认打开 GUI。旧控制台菜单保留为 `bmc_toolkit.exe --interactive`，请从已有终端运行。原有 CLI 命令继续可用。

## 正式服生成

1. 在“生成资料”选择“正式服在线”，勾选需要的资料，设置输出目录。
2. 点击“检查所需资源”查看计划。此步骤可能下载 masterdata 以识别任务依赖，但不生成表格；正式清单收录不等于内容已在游戏内开放。
3. 点击“同步并生成”。通过校验的已有缓存会复用，卡牌语音可以取消勾选以减少下载。
4. 在“本次文件”选择文件并打开；有告警时查看“运行详情”，确认缺项后再使用结果。

“主页 / 生日祝福”来自 ACB 语音元数据；“生日庆典台词”来自 masterdata，两者不是重复任务。在线谱面路径尚未确认，谱面请使用本地资源。

## 离线、本地和旧卡表

- “正式服离线缓存”只使用已有且校验通过的正式资源缓存，不会联网补齐缺项。高级设置可指定缓存目录。
- “使用本地资源”不联网。在“输入与高级设置”指定 masterdata、ACB 目录或独立文件。添加文件按扩展名预填入口，文件内容会在生成时严格校验。
- 更新人工维护的卡表时，选择“更新已有卡表”，在高级设置选择旧 XLSX。在线模式取得新 masterdata；本地模式还需选择新 masterdata。中文和自定义列的保留规则见 [卡表更新说明](CARD_UPDATE_MODE.md)。

## 输出与失败处理

普通 XLSX/LRC 位于输出目录的 `wiki_output`；诊断 JSON/Markdown、资源来源和本次产物清单位于 `audit_output`。剧情和谱面本身的 JSON 也是用户请求的成果，会显示在本次文件列表中。

文件列表只使用本次任务登记的产物。失败任务已经写出的文件标记为“不完整”；历史目录里仍可能保留旧文件，不能以目录里存在文件判断本次成功。Excel 占用目标时会使用替代文件名，以列表中的实际路径为准。

取消会等待当前解析步骤结束；下载也受超时约束，因此不一定瞬间停止。运行中关闭窗口会请求取消并等待工作线程退出。完成后可以调整输入并重试。

设置保存到 `%LOCALAPPDATA%/BRMYWikiToolkit/settings.json`，默认缓存位于同目录的 `cache`。真实资源和导出文件均不进入 Git 仓库。

## 验收边界

`python -m toolkit gui --self-test` 只构造隐藏窗口，验证 Tk 与组件可以加载；不能证明可见布局、点击流程、缩放或真实任务正确。五项正式源 GUI 任务和冻结共享服务已验收；本地生日表经 GUI 生成后与正式源表逐格等值，已验证按钮打开 Excel 及 Excel 占用时的替代保存。详细范围见 [审计记录](AUDIT_RECONCILIATION_20260908.md)，正式发布另需满足 [发布门槛](RELEASE_BUILD.md)。

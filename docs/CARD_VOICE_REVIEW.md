# 卡牌语音待核对清单

卡牌语音文本来自 ACB 的 `title:{}text:{}` 元数据。这些元数据是人工写入的，存在复制粘贴：例如「結婚、か」同时出现在 418、431、432 的技能语音上。卡牌全表照原样输出 ACB 文本，**不自动改写**；可疑条目另外列成待核对清单，请编辑试听后修正。

## 何时生成

`cards` 和 `card_update` 任务在提供卡牌 ACB 时自动生成，不需要额外选项：

- `wiki_output/card_voice_review.xlsx`：待核对清单，最后有一列“核对后台词J（人工）”
- `audit_output/card_voice_review.json`：同样的条目，加上扫描告警和跳过的抽卡 Cue 数量

## 问题类型

| 类型 | 判定 |
| --- | --- |
| 跨卡重复（较晚出现） | 同一句话（去掉换行和空白后比较）出现在两张以上的卡上，且此卡不是其中发布最早的一张。最可能是复制来的，请优先核对 |
| 跨卡重复（最早出现） | 同上，但此卡发布最早，推测是原句，仍需确认 |
| 同卡不同Cue重复 | 同一张卡的两条语音文本完全相同 |
| 文本为空 | Cue 存在，但文本为空 |
| 元数据格式损坏 | 不符合 `title:{}text:{}` 格式；卡牌表里此条为空，原始内容放在“原始元数据”列 |

“最早出现”只是按发布时间做的推测，不代表这一句一定正确。

## 范围

- 抽卡语音（`card_vo_gacha`）不检查：卡牌全表不导出它，而且 2025 年中以后的卡大多没有填写抽卡语音文本。
- 三轮生日卡逐段的协作语音不在本清单内，见 [多段协作语音例外表](CARD_COMBI_VOICES.md)。
- 2026-11-07 正式服数据（495 张卡）：43 条，其中跨卡重复 35 条、空文本 8 条。

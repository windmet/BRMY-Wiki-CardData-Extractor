## Story Scripts (.s2bscript)

Format: 4-level nested JSON
```
[scene_array [command_array [id, next_ids, type, action, params]]]
```

Key command types:
- **Chat**: dialogue with `chatTitle` (speaker), `chat` (text), `voiceName` (audio cue), `balloonType`, `emotion`
- **Image**: background with fade `time`
- **Chara**: character show/hide/move with `time`
- **Other/Wait**: explicit wait with `time`
- **Other/All**: scene transition with `time`

Chat timing: NOT in script. Computed at runtime via:
- `chatEndWaitTimeWithoutVoice` (Unity prefab field, value TBD)
- `chatEndWaitTimeWithVoice`
- `GetMessageWaitMultiplierBasedOnLetterSpeed`

Voice detection: `voiceName` field non-empty = voiced line.
Currently found: main story (main_*.s2bscript), card stories (card_*.s2bscript), event stories (campaign_*.s2bscript, event_voice_story_*.s2bscript)

## Cpp2IL / IL2CPP Metadata

- Cpp2IL 2022.1.0-pre-release does NOT support metadata v31
- Need latest Cpp2IL or re-run Il2CppDumper with field defaults flag
- Android APK structure needed: `lib/arm64-v8a/libil2cpp.so` + `assets/bin/Data/Managed/Metadata/global-metadata.dat`

## Timing Formula (Empirical)

From SRT data (card_357_7_1, 36 lines, Normal letter speed):
- Unvoiced: `1.3s + char_count × 0.07s`
- Voiced: `2.0s + char_count × 0.15s` (朗读 estimate)
- Scene transitions add: Image(0.5s), Chara Show(0.2s), Wait(0.2s), All(1.0s)
